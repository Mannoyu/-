# 画面元素编辑

打开 `/workbench`，在预览上点击卡片、标题、副标题、字幕或进度条，即可选中并编辑。右侧「画面」的图层列表也能选择未出场、被遮挡的图层，以及光晕、指示器、遮罩和暗角。

- 拖动选框移动，拖动右下角方块缩放。方向键微移，Shift 加方向键移动 10 像素。
- 每张卡片可独立调整，也可以选择「卡片组」整体调整。时间线「片段」里的卡片位置仍按所选片段保存；画面图层的偏移在这个基础上叠加。
- 选择单张卡片后，可修改底部标题、编号及角标文字，也可关闭卡片文字。标题和编号留空时跟随素材及自动编号。
- 位置、大小、旋转、不透明度和显示开关均会自动保存。选框聚焦时按 Delete 隐藏该图层，可从图层列表重新显示。
- 标题与副标题可以修改文案、字号和颜色；标题输入框支持换行。
- 出场可选原始动画、无动画、淡入、向上、从右和缩放。自定义动画支持开始时间和持续时长。「预览出场」从指定时间播放。
- 在「右侧标题」的「文字效果」里选「字内流光」，高光随播放时间在笔画内循环。预览、拖动播放头和导出都按同一个时间取样。
- 「字幕」中可在播放头添加一句、导入 LRC、修改原文和译文、起止时间、字号、对齐、颜色及入场动画。新句插入当前字幕中间时会截断前一句，并以后一字幕的开始时间限制结束时间。
- 双击画面字幕可打开当前一句的编辑；双击标题或副标题可聚焦文字输入框。
- 「整曲保留标题」可以和字幕同时使用，字幕默认位于标题下方，也可通过字幕图层调整位置。
- 以上修改接入自动保存、撤销和重做，也会随模板保存。预览与导出使用同一份草稿画面快照。

图层是视频里的独立合成元素。背景素材中已经拍摄或烘焙进去的人物、花朵和文字仍属于视频像素，不能作为独立图层选择。

实现：`scene-editor-model.mjs` 负责属性校验和按时间计算入场，`scene-editor-runtime.js` 同时供预览和导出使用，`workbench-elements.js` 负责选择和交互。导出指纹包含这些文件，以免修改动画后复用旧画面缓存。
