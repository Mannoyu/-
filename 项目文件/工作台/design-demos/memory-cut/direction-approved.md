# 新一轮方向：错位唱片封套

用户原话：“你不要管之前全部长什么样，你只要按你自己的想法来，不要被当前模板的想法束缚住，要更有创新一点点，就不要管之前是怎么样，你就按自己的想法来。”

据此在同一项目迭代中脱离旧模板，独立制作一版试听，保留原音乐与真实素材但不保留左卡右词结构。原工程不改。

创意：以斜切与错位影像表达歌曲中追寻、分离和破碎的情绪。动态画面铺满，另一幅更近的影像形成切口另一侧；歌词用唱片封套式大字形成前景，切换素材时沿切口揭开。

镜头固定。主歌与副歌共享影像母题，但普通日文是两到三行紧凑标题；英文词组以更大的斜体独立落位。每句读稳后停止位置移动，短显字不是逐字同步。

试听选段沿用原歌曲 20.92–38.97、38.97–53.67 和 79.03–95 秒。每段小于20秒，保留原音轨，不另加音效。
