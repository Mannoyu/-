# 音乐可视化项目

双击项目根目录的 [打开工作台.cmd](../../打开工作台.cmd)，在浏览器访问终端显示的地址。常用位置见 [目录说明](../../先看这里.md)。

工作台启动后会恢复上次编辑的草稿。上方可切换或根据当前设置新建草稿。左侧可导入素材、预览模板和套用模板。底部可拖动背景切换点，点击片段即可定位到相应的背景或歌词。右侧可修改取景、修剪背景、调整模板布局或选中一句歌词单独编辑。草稿在修改后自动保存。

原有单曲预览仍可通过 `/editor` 打开。草稿和导入素材由 `workspace/` 管理，其中 `state.json` 记录草稿与模板，`media/` 保存导入素材，`scenes/` 保存供预览和导出共用的画面快照。

## 导出

「导出画质预览」按最终视频帧率取样，使用与导出相同的逐帧素材。编辑器实时播放速度取决于设备。「导出视频」支持单遍、按遍数循环和按分钟循环，最长 60 分钟。当前歌曲循环 10 遍约为 36 分 23 秒。画面规格为 1920×1080、60 fps，默认 CRF 13。重复导出可复用 `.showreel-editor/video-cache/` 中的画面。

成片直接保存到 Windows 当前账户的实际桌面目录（支持系统重定向的桌面），完成后显示完整路径并可在资源管理器中定位。工作台播放读取桌面上的同一份文件，下载按钮已替换为定位按钮，不再在项目中留一份成片。桌面文件占用本机磁盘空间，由用户保管或删除。导出过程中的临时 MP4 在桌面、临时音频在 `workspace` 中，正常结束或失败时清理。

剪辑工作台的升级范围与验收顺序见 [开发计划](../../开发计划.md)。历史版本见 [版本记录](archive/版本记录.md) 和 [制作记录](archive/brief.md)。

## 存储管理

素材库的「移除」保留恢复能力；展开「已移除素材」，点击「永久删除」才会清除对应本地视频、音频和逐帧文件。仍被任意草稿或模板引用的素材不能删除，导出期间也不能删除。

同一项目重复启动会复用已运行的工作台，避免重复占用服务进程。删除操作使用逐项删除及结果核验，绕过本机 Node 在中文路径下 `rm` 返回后文件仍残留的问题。

渲染缓存自动保留最多 2 GiB，混音缓存最多 512 MiB，超过 7 天未使用的缓存会清理。启动、导出结束和每隔 30 分钟执行维护；导出进行中暂停清理，因此渲染时可以暂时超过限额。画面快照保留最近 7 天，重新打开草稿时会生成所需快照。素材库的「存储清理」还可以立即清空渲染缓存。

导入过程记录待登记素材，失败会回收本批生成文件；进程中断后，下次启动会清理未登记的本批产物。无法确认来源的历史孤立素材不自动删除。

桌面成片、原始素材和采集依赖不属于缓存，不会自动清理。长循环成片可能占用数 GiB，需要时从桌面移动到归档磁盘。上述限额约束缓存，不限制成片和仍保留的素材总量。

命令行盘点：`node storage-cleanup.mjs`（默认只预览）；清理缓存：`node storage-cleanup.mjs --apply`；连同无引用的已移除素材一起永久删除：`node storage-cleanup.mjs --apply --removed`。运行命令行清理前请停止工作台服务，避免与界面操作并发。清理结果写入 `storage-maintenance-report.json`。回归检查：`node --test storage.test.mjs`。
