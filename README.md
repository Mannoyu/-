# 音乐剪辑工作台

浏览器中的本地音乐视频剪辑工作台，包含独立背景片段、音频切换、歌词编辑、卡片布局、预览和桌面视频导出。

## 功能

- 独立片段分割、移动、修剪、删除留空和填入背景。
- 切换音乐保留背景及字幕，提供真实音频能量波形。
- 卡片位置与大小调整，自动保存、撤销和重做。
- 石墨灰与低饱和蓝色的共享前端主题。
- 1080p / 60 fps 导出到 Windows 桌面。
- 素材引用保护、导入失败回收和有容量及时间限制的渲染缓存。

## 目录

- `项目文件/工作台/`：前端、服务端、渲染和测试源码。
- `项目文件/素材处理工具/`：素材准备及诊断脚本。
- `docs/`：交互升级方案和架构记录。
- `先看这里.md`：本地项目的使用与目录说明。

## 运行环境与素材

这是现有本地项目的代码仓库。视频、歌曲、逐帧图片、草稿状态、工具二进制、依赖安装目录和缓存不提交到 Git；克隆仓库后需另行准备素材和本地依赖，不能仅运行 `npm install` 就得到完整工作环境。

当前启动及导出模块依赖本机 Codex 的 `motion-showreel` 运行库，代码中仍有 `C:/Users/123/.codex/skills/motion-showreel/` 路径。迁移至其他电脑时，需要安装对应运行库、调整这些路径，并准备 Node.js、Python 和 FFmpeg。具体入口与本地数据布局见 [工作台说明](项目文件/工作台/README.md)。

已有素材和运行依赖的原电脑上，双击 `打开工作台.cmd`，或进入 `项目文件/工作台/` 运行：

```sh
node open-preview.mjs
```

访问启动日志显示的 `/workbench` 地址。
